جمله‌ها و موقعیت‌ها کاربردهای کاری، مالی، همسایگی، سفر و خدمات، آموزش، سلامت، حریم خصوصی، پایداری، سواد رسانه‌ای، فرهنگ، روابط و مشارکت اجتماعی را پوشش می‌دهند. الگوهای زبانی در بافت شامل جمله‌های وابسته و موصولی، روایت گذشته، دلیل و تضاد، شرط و پیامد، Konjunktiv II برای درخواست مؤدبانه، مجهول با و بدون فعل وجهی، دستورالعمل و مکاتبهٔ رسمی است.

درس پایانی تمرین ترکیبیِ بدون نمره است؛ آزمون، گواهی یا تأیید مهارت نیست. خودارزیابی گفتار و دسترسی به قابلیت‌های فعلی دستگاه باقی مانده‌اند؛ هیچ سرویس پولی یا ارزیابی گفتار مبتنی بر هوش مصنوعی اضافه نشده است.

## رابط و پیشرفت

۲۵ عنوان در کتابخانهٔ B1 با درس‌ها هم‌راستا هستند و کتابخانه آن‌ها را در پنج گروه پنج‌درسی نمایش می‌دهد. شمار درس، جمله و واژگان از کاتالوگ محاسبه می‌شود. اضافه‌کردن درس‌ها شناسه‌های قبلی، کلید ذخیرهٔ پیشرفت یا محتوای Pre-A1، A1، A2، انگلیسی و روسی را تغییر نمی‌دهد.

## بررسی فنی

- `npm run typecheck`
- `npm run validate:german-levels` — موفق، **۹۷۱ بررسی**؛ حفظ شناسه‌های قدیمی، توالی درس‌ها، ترجمه/تلفظ/واژگان، تعداد جمله‌ها و هم‌راستایی موضوع‌های B1.
- `npm run validate:logic` — موفق، **۱٬۵۷۰ بررسی**؛ شمار کل جدید و جداسازی پیشرفت زبان‌ها.
- `npm run validate:content` — موفق؛ ۱۶۱ درس انگلیسی و پوشش ۵۰۴/۵۰۴ واژه.
- `EXPO_OFFLINE=1 npm run build:web` — موفق؛ ۳۷ مسیر ایستای وب ساخته شد.
- `scripts/verify-language-home.cjs` — **۴۵ بررسی مرورگر** موفق؛ مسیرهای سه زبان، نمایش B1 در کتابخانه و شمارهای آن در عرض‌های ۳۲۰، ۳۹۰ و ۱۲۸۰ پیکسل.
- محیط آزمون اجازهٔ دسترسی به CDN اختیاری `jsQR` را نمی‌دهد؛ آزمون فقط همان خطای بارگذاری worker را فیلتر می‌کند. این سناریو دوربین/اسکن QR را اعتبارسنجی نمی‌کند. آزمون کامل `verify-german-journey.cjs` در این محیط اجرا نشد.

این بررسی‌ها ساختاری/تحریری‌اند؛ بازبینی مستقل مدرس آلمانی، پژوهش با زبان‌آموز واقعی یا اعتبارسنجی رسمی CEFR ادعا نمی‌شود.
