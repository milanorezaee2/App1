# راه‌اندازی بدون ترمینال (فقط با مرورگر)

هدف: روشن‌کردن «کد دعوت» و بقیه امکانات سروری اپ، بدون هیچ دستور ترمینالی.
زمان لازم: حدود ۵ دقیقه. هزینه: پلن رایگان Supabase کافی است (کارت بانکی لازم نیست).

> دستورهای `npx supabase login` و `./scripts/setup-production.sh` که در README-FA هست،
> **اختیاری** است. همان نتیجه‌ای که آن اسکریپت می‌سازد، با SQL Editor داشبورد هم
> گرفته می‌شود؛ تفاوتشان فقط در محیط اجراست و بک‌اند یکسانی تولید می‌کنند
> (این ادعا در همین پروژه با اجرای واقعی SQL روی دو مسیر تست شده است).

---

## قدم ۱ — ساخت پروژه Supabase (اگر ندارید)

1. برو به <https://supabase.com> و با ایمیل یا GitHub ثبت‌نام کن.
2. دکمه **New project**.
3. یک نام بگذار (مثلاً `companion-english`)، رمز دیتابیس را جایی ذخیره کن.
4. یک منطقه (Region) نزدیک خودت انتخاب کن و **Create new project** را بزن.
5. حدود ۱ تا ۲ دقیقه صبر کن تا پروژه آماده شود.

## قدم ۲ — ساخت جدول‌ها و توابع کد دعوت (مهم‌ترین قدم)

1. در منوی سمت چپ پروژه، روی **SQL Editor** بزن.
2. دکمه **New query**.
3. فایل زیر را از مخزن باز کن و **کل محتوایش** را کپی کن:
   `supabase/SETUP-COPY-PASTE-ONCE.sql`
4. متن را در همان کادر SQL Editor پیست کن و دکمه **Run** (یا Ctrl+Enter) را بزن.
5. باید پیام **Success. No rows returned** ببینی. تمام.
   - این فایل خودش همه‌چیز را می‌سازد: جدول دستگاه‌ها، جدولهای گفتگوی خصوصی،
     و دو تابع `create_contact_invite` و `claim_contact_invite` که کد دعوت ۶ رقمی
     را تولید و مصرف می‌کنند.
   - همه دستورها با `IF NOT EXISTS` نوشته شده‌اند؛ اگر دوباره اجرا کنی هیچ خطایی نمی‌دهد.

> نکته: اگر ترمینال نداری نگران نباش — این تنها کاری است که آن اسکریپت هم انجام می‌داد.

## قدم ۳ — روشن‌کردن ورود ناشناس (اجباری)

بدون این قدم، اپ نمی‌تواند هویت بسازد و **کد دعوت هرگز تولید نمی‌شود**.

1. منوی چپ: **Authentication**.
2. سربرگ **Sign In / Providers** (در برخی نسخه‌ها فقط **Providers**).
3. گزینه **Anonymous sign-ins** را پیدا کن و **ON** کن.
4. **Save**.

## قدم ۴ — برداشتن دو مقدار برای فایل `.env`

1. منوی چپ: **Project Settings** (چرخ‌دنده) → **API**.
2. این دو مقدار را بردار:
   - **Project URL** — مثل `https://abcdefgh.supabase.co`
   - **anon public** key (کلید عمومی، رشته‌ای بلند که با `eyJ...` شروع می‌شود)
3. این دو مقدار را در فایل `.env` این مخزن بگذار، خط ۱۳ و ۱۴:
   `EXPO_PUBLIC_SUPABASE_URL=` و `EXPO_PUBLIC_SUPABASE_ANON_KEY=`

می‌توانی همین دو مقدار را در چت بدهی تا من در فایل `.env` بگذارم و پیش‌نمایش را
دوباره اجرا کنم.

> امنیت: این دو مقدار **عمومی** هستند و عمداً داخل خود اپ/APK قرار می‌گیرند؛
> پس Share کردنشان حساس نیست. اما کلید **service_role** (در همان صفحه API،
> بخش Project API keys) کلید مدیر است — آن را **هرگز** در `.env`، در Git یا در چت
> قرار نده.

## قدم ۵ (اختیاری) — Emma با هوش مصنوعی واقعی

کد دعوت و چت و تماس صوتی به این قدم نیازی ندارند. فقط برای Emma واقعی لازم است:

1. منوی چپ: **Edge Functions** → **Create function**.
2. نامش را `emma-chat` بگذار و محتوای `supabase/functions/emma-chat/index.ts` را
   داخلش پیست کن و Deploy کن. همین کار را برای `speech-evaluate` و
   `human-chat-assist` و `turn-credentials` تکرار کن.
3. در **Project Settings → Edge Functions → Secrets** این‌ها را اضافه کن:
   `OPENAI_API_KEY`، `OPENAI_MODEL`، `OPENAI_TRANSCRIBE_MODEL`
   (کلید AI را هرگز داخل اپ یا Git نگذار.)

## بعد از این کارها

به من بگو «انجام شد» تا سرور پیش‌نمایش را با `npx expo start -c` دوباره بالا
بیاورم (Expo مقادیر `.env` را فقط هنگام باندل‌شدن می‌خواند). بعد در اپ:
**گفتگوها → افزودن مخاطب دیگر** باید یک کد ۶ رقمی نشان بدهد.

## عیب‌یابی سریع

| نشانه | علت | راه‌حل |
|---|---|---|
| کد نشان می‌دهد `------` و پیام «توابع ساخت کد دعوت اجرا نشده‌اند» | فایل SQL اجرا نشده | قدم ۲ |
| پیام «ورود ناشناس ... فعال نشده است» | Anonymous sign-ins خاموش است | قدم ۳ |
| پیام «برای این بخش باید اتصال Supabase تنظیم شود» | `.env` خالی یا مقادیر نمونه | قدم ۴ |
| پیام «ارتباط با سرور Supabase برقرار نشد» | اینترنت یا غلط‌بودن URL/کلید | قدم ۴ را دوباره چک کن |
| کد ساخته می‌شود ولی دوستت نمی‌تواند وارد کند | کد خودت را وارد کرده، یا کد قدیمی است | کد را برای شخص دیگر بفرست؛ کد ۲۴ ساعت اعتبار دارد و با هر بار باز کردن صفحه، کد قبلی باطل می‌شود |
