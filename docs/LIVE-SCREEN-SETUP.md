# اپ مستقل گوشی دوم — Companion English

این مخزن فقط APK گوشی دوم را تولید می‌کند. شناسه اندروید آن `com.devicecontrol.companion` است و مستقل از اپ مدیریت گوشی اول نصب می‌شود.

## معماری

- **گوشی اول:** اپ Controller جداگانه؛ پنل مدیریت و دریافت تصویر.
- **گوشی دوم:** همین پروژه؛ اتصال، ارسال وضعیت، اشتراک رضایتی صفحه و آموزش زبان.
- **ارتباط:** Supabase برای جفت‌سازی و سیگنال WebRTC؛ TURN برای اتصال مطمئن روی اینترنت عمومی.

## راه‌اندازی سرور

1. فایل `supabase/SETUP-ALL-IN-ONE.sql` را در SQL Editor پروژه Supabase اجرا کنید.
2. متغیرهای زیر را هنگام ساخت APK تنظیم کنید:
   - `EXPO_PUBLIC_SUPABASE_URL`
   - `EXPO_PUBLIC_SUPABASE_ANON_KEY`
   - `EXPO_PUBLIC_TURN_URL`
   - `EXPO_PUBLIC_TURN_USERNAME`
   - `EXPO_PUBLIC_TURN_CREDENTIAL`

TURN در یک Wi-Fi معمولاً ضروری نیست، اما برای ارتباط پایدار بین اینترنت سیم‌کارت و اینترنت خانگی لازم است.

## عملکرد APK گوشی دوم

1. برنامه مستقیماً وارد صفحه Companion می‌شود؛ پنل مدیریت یا انتخاب نقش ندارد.
2. کاربر کد شش‌رقمی اپ اول را وارد می‌کند.
3. اطلاعات مجاز دستگاه برای اپ اول ارسال می‌شود.
4. اشتراک صفحه فقط پس از فشردن دکمه و تأیید پنجره رسمی Android MediaProjection آغاز می‌شود.
5. هنگام اشتراک، اعلان دائمی اندروید قابل مشاهده است.
6. آموزش زبان، تلفظ، فلش‌کارت و آزمون داخل همین APK در دسترس است.

صفحات محافظت‌شده با `FLAG_SECURE` ممکن است در تصویر زنده سیاه دیده شوند. کنترل لمس، مرحله جداگانه‌ای است و به فعال‌سازی دستی Accessibility Service روی گوشی دوم نیاز دارد.
