# ممیزی ایستای دسترس‌پذیری — مسیرهای اصلی انگلیسی

## کار انجام‌شده

`npm run validate:a11y` با TypeScript compiler API، JSX/TSX را بدون مرورگر می‌خواند. این ممیزی روی ۱۳ فایل صفحه/کامپوننت (خانه، درس، مکالمه، سنجش آغازین، مکمل، کتابخانه، بازی جمله، پشتیبان و کنترل‌های سطح) این قراردادهای قابل‌بررسی در کد را می‌آزماید:

- هر `Pressable` نقش تعاملی اعلام‌شده دارد؛ کنترل‌های صرفاً آیکونی برچسب صریح دارند و کنترل‌های متنی متن قابل‌خواندن دارند؛
- کنترل غیرفعال وضعیت disabled را به درخت دسترس‌پذیری می‌دهد؛ انتخاب‌های radio/checkbox وضعیت checked دارند؛
- فیلدهای `TextInput` برچسب دسترس‌پذیری دارند؛
- عنوان صفحهٔ پشتیبان ساختار heading دارد و پیام وضعیت/خطا برای فناوری کمکی علامت‌گذاری شده است.

در جریان ممیزی، برای پخش صوت، دکمه‌های ضبط خاموش، آزمون درس، پیشنهاد مکالمه، ضبط پیام صوتی و فیلدهای ورودی برچسب/وضعیت واضح اضافه یا اصلاح شد. آیکون بی‌عمل در کادر Emma از کنترل ظاهری به عنصر تزئینی تبدیل شد.

## محدودیت

۲۱۱ بررسی ایستا فقط قراردادهای مشخص بالا را می‌سنجد؛ این **گواهی WCAG یا تکمیل ممیزی دسترس‌پذیری نیست**. خوانایی/کنتراست در دستگاه واقعی، ترتیب و وضوح فوکوس صفحه‌کلید، رفتار Zoom/Reflow، معنای کامل زنده برای صفحه‌خوان فارسی، تلفظ متن انگلیسی و آزمون در Safari/Chrome/Android/iOS همچنان نیازمند بررسی دستی‌اند. در این کار مرورگر یا پکیج مرورگر نصب نشد؛ آزمون صفحه‌خوان/دستگاه انجام‌شده ادعا نمی‌شود.
