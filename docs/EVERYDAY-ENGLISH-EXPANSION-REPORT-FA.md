# گزارش گسترش و تکمیل Everyday English

**مرحلهٔ مستندشده:** گسترش Everyday English، ۱۱ اکتبر ۲۰۲۶  
**هدف مصوب:** حفظ ۲۰ درس موجود و رساندن هر درس به دست‌کم ۵۰ نمونهٔ جمله  
**نتیجهٔ این مرحله:** ۲۰ درس × ۵۰ نمونه = **۱٬۰۰۰ جمله**؛ شامل **۸۲۰ جملهٔ تازه**

> پس از این مرحله، ۳۹۶ نمونهٔ دیگر به ۹ درس قدیمی Communication English افزوده شد؛ در مرحلهٔ جاری نیز شش درس Communication با ۳۰۰ جمله اضافه شدند. آمار فعال اکنون ۱۷۴ درس/۳٬۸۶۲ جمله است و Communication برابر ۱۵ درس/۷۵۰ جمله است. گزارش جاری در `docs/COMMUNICATION-ENGLISH-50-EXAMPLES-REPORT-FA.md` و نقشهٔ ادامه در `docs/ENGLISH-CURRICULUM-REBUILD-REPORT-FA.md` آمده‌اند. جدول این سند و شمارهای اعتبارسنجی آن snapshot پایان گسترش Everyday و پیش از Communication را ثبت می‌کنند.

> در گزارش مرحلهٔ پیشینِ ۱۰ اکتبر، Everyday بیست درس و ۱۸۰ جمله داشت. این مرحله همان بیست درس و همهٔ جمله‌های قبلی را حفظ کرده و فقط مثال‌های تکمیلی را به انتهای همان درس‌ها افزوده است؛ موضوع تکراری تازه‌ای برای رسیدن به حداقل تعداد درس‌ها ساخته نشد.

## کیفیت محتوا و حفظ سازگاری

- هر نمونهٔ تازه متن انگلیسی، ترجمهٔ فارسی، راهنمای تقریبی تلفظ و الگوی جمله دارد؛ برای هرکدام دست‌کم دو مدخل واژگانیِ معنادار و متصل به همان جمله ثبت شده است.
- پیوند واژگان با متن انگلیسی به‌صورت خودکار بررسی می‌شود. صورت واژگانِ صرف‌شده و عبارت‌های چندواژه‌ای هم با همان بافت واقعی جمله تطبیق داده شده‌اند.
- در ممیزی نهایی، پس از یکسان‌سازی حروف، فاصله‌ها و نشانه‌گذاری، میان ۱٬۰۰۰ جملهٔ Everyday گروه تکراری پیدا نشد و هیچ‌یک از ۸۲۰ مثال تازه با مثال دیگری در مسیر فعال انگلیسی تکرار نمی‌شود.
- شناسه و ترتیب درس‌ها، شناسه و متن مثال‌های قبلی و گفت‌وگوهای موجود دست‌نخورده ماندند؛ ۸۲۰ مثال تازه پس از نمونه‌های قبلی هر درس قرار گرفتند. زمان تخمینی درس‌های تکمیل‌شده اکنون ۳۵ دقیقه است.
- ساختار پیشرفت و کلید ذخیره‌سازی `sentence_course_progress_v1` تغییر نکرد. تمرین‌های شاهد یادگیریِ ۱۵ درس تازه نیز همان شش سنجش قبلی را نگه می‌دارند.
- یکتاسازی `vocabulary.word` در کل Everyday اکنون **۱٬۷۷۴ مدخل/عبارت** به دست می‌دهد؛ عبارت‌های چندواژه‌ای یک مدخل شمرده می‌شوند. این آمار تعداد واژه‌های یکتای ثبت‌شده است، نه ادعای تسلط زبان‌آموز.

## اعتبارسنجی‌ها

| فرمان | نتیجه |
|---|---|
| `npm run typecheck` | موفق؛ بدون خطای TypeScript |
| `npm run validate:content` | موفق؛ ۱۶۸ درس/۳٬۱۶۶ جمله، شامل Everyday برابر ۲۰/۱٬۰۰۰؛ پوشش ۵۰۴/۵۰۴ |
| `npm run validate:logic` | موفق؛ ۱٬۵۹۸ بررسی روی مسیرهای ذخیره‌سازی وب و بومی |
| `npm run validate:english-engine` | موفق؛ ۲٬۳۷۰ بررسی، از جمله ترتیب، شمار، یکتایی و اتصال واژگان Everyday |
| `npm run validate:english-four` | موفق؛ ۲٬۰۹۵ بررسی منطقی و محتوایی |
| `npm run validate:english-supplement` | موفق؛ ۱٬۸۷۷ بررسی؛ مسیر مکمل ۲۴واحدی جدا ماند |
| `npm run validate:russian` | موفق؛ ۲۵ بررسی؛ مسیر روسی دست‌نخورده ماند |
| `EXPO_OFFLINE=1 EXPO_NO_TELEMETRY=1 npm run build:web` | موفق؛ ۳۷ مسیر وب ساخته شد |
| سه فرمان `node --check` جداگانه برای `verify-english-four-browser.cjs`، `verify-english-engine.cjs` و `verify-english-four.cjs`؛ همچنین `git diff --check` | موفق |

آزمون تعاملی Playwright اجرا نشد و Chromium نصب یا دانلود نشد. ساخت وب بدون نیاز به مرورگر انجام شد. هشدارهای ساخت دربارهٔ قدیمی‌بودن داده‌های Browserslist/Baseline و یک `require` پویا غیرمسدودکننده بودند.

## مرز ادعا

این گزارش شمار، ساختار داده و نتیجهٔ آزمون‌های خودکار مخزن را ثبت می‌کند. سطح داخلی A2–B1 به معنی اعتبارسنجی رسمی CEFR نیست؛ ارزیابی مستقل مدرس، گواهی سطح، تضمین تسلط فردی یا سنجش گفتار و تلفظ ارائه نمی‌شود.
